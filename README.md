# 🎬 Movies SQL Analytics Project

## About
A SQL analytics project where I analyse movie data to find insights 
about ratings, genres, directors and more.

## Tools Used
- SQL (SQLite)
- DB Browser for SQLite

## Queries
1. **Top 5 highest rated movies** - Finding the best movies by rating
2. **Most prolific directors** - Which director has the most movies?
3. **Average rating by genre** - Which genre has the best ratings?
4. **Longest movies** - Top 5 movies by runtime
5. **International movies** - Movies produced outside the USA

## What I Learned
- Writing SQL queries from scratch
- Using SELECT, WHERE, GROUP BY, ORDER BY and LIMIT
- Using aggregate functions like COUNT, AVG and MAX
- Analysing real data to find meaningful insights
